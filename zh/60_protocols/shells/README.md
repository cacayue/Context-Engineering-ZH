# 协议壳（Protocol Shells）

本目录收录协议壳（shell）定义——把语义场上的操作固化为结构化、可递归的协议，是 `60_protocols` 工程资产的核心。每个协议壳描述一类场操作：吸引子共涌现、递归涌现、记忆吸引子、场共振脚手架、场自修复、上下文记忆持久化。

**章节导览**

- **吸引子共涌现协议壳** — `attractor.co.emerge.shell.md`
- **上下文记忆持久化吸引子协议壳** — `context.memory.persistence.attractor.shell.md`
- **场共振脚手架协议壳** — `field.resonance.scaffold.shell.md`
- **场自修复协议壳** — `field.self_repair.shell.md`
- **记忆重构吸引子协议壳** — `memory.reconstruction.attractor.shell.md`
- **递归涌现协议壳** — `recursive.emergence.shell.md`
- **递归记忆吸引子协议壳** — `recursive.memory.attractor.shell.md`

**阅读建议**

协议壳中带语言标记的代码块（yaml/python）保留语法结构，块内自然语言说明按全书术语对照译为中文；无标记的说明块与 ASCII 图原样保留。建议先读 `digests/` 下的简化说明建立直觉，再回到这里研读完整协议定义。
