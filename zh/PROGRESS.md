## 4. 状态机

```text
todo ──▶ draft ──▶ review ──▶ published
  ▲                       │
  └──── sync-needed ◀─────┘   (上游 sha 变化)
authored：无原文，todo ──▶ published
```

| 状态 | 含义 | 计入覆盖率 |
|---|---|---|
| `todo` | 未开始 | 否 |
| `draft` | 段已译完，未自检 | 是 |
| `review` | 自检通过，待二次校对 | 是 |
| `published` | 校对完成 | 是 |
| `authored` | 无原文，AI 原创 | 否 |
| `sync-needed` | 上游变了，原译文保留 | 否 |

## 5. 取活规则

```text
1. 读本文件 §0 → 取「下一步」指向的任务
2. 读 zh/manifest.json → 取该任务内第一个 status == todo 的文件
3. 若 chunks_done 非空 → 从 max(chunks_done)+1 继续（断点续跑）
4. 每完成一段：写 chunk 注释 + 追加 chunks_done
5. 全部段完成：python zh/tools/check.py <文件> → 绿则 status: review
6. 会话结束：python zh/tools/progress.py 重新生成本文件
```
