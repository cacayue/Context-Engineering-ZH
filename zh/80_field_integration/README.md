# 场整合（Field Integration）

本目录用于收纳把场论方法整合进实际系统的材料。上游仓库此目录暂无正文，中文镜像保留位置，供后续补充跨协议壳的场编排方案、共振脚手架组合与自修复机制。

**本目录应包含什么**

- **场编排方案** — 多个协议壳如何在同一语义场上协同运作。
- **共振与自修复** — 场共振脚手架、场自修复协议壳的组合模式与失效边界。
- **与课程的关系** — `00_COURSE/08_field_theory_integration/` 给出理论与协议定义，本目录收纳的是把它们落到具体工程场景的整合经验。
- **评估与观测** — 场收敛性、吸引子稳定性与残差分布的度量方式。

**阅读建议**

先读 `00_COURSE/08_field_theory_integration/` 的神经场基础与吸引子动力学，再读 `60_protocols/shells/` 下的协议壳定义，最后回到本目录设计自己的整合方案。术语沿用全书：field=场、attractor=吸引子、resonance=共振、emergence=涌现、orchestration=编排。
