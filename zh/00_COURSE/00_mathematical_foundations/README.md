# 数学基础（Mathematical Foundations）

本模块为上下文工程建立数学基础，把直觉性的设计原则转化为可度量、可优化的形式化语言。建议按顺序学习：先理解上下文的形式化表示，再掌握在有限预算下寻找最优上下文装配的优化理论，进而用信息论量化上下文质量与相关性，最后以贝叶斯推断实现上下文的概率式自适应。
