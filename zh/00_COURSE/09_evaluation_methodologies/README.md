# 评估方法论（Evaluation Methodologies）

本模块系统讲解如何评估上下文工程系统：从整体评估框架出发，深入到组件级评估与系统集成评估，最后落到基准设计。建议按顺序学习：先建立评估的维度与原则，再分别掌握组件与系统的评估方法，最终学会设计可复用、可比较的基准。
