# 上下文检索与生成实验（Retrieval & Generation Labs）

本目录提供上下文检索与生成模块的配套实验脚本。三个 Python 实验分别对应提示词工程、外部知识检索与动态上下文装配，建议在掌握对应章节后按序动手实践。

**章节导览**

- **提示词工程实验** — `labs/prompt_engineering_lab.py`
- **知识检索实验** — `labs/knowledge_retrieval_lab.py`
- **动态装配实验** — `labs/dynamic_assembly_lab.py`
