# 检索增强生成（Retrieval-Augmented Generation）

本模块把外部知识检索接入语言模型的生成过程，系统讲解检索增强生成（RAG）从基础理论到前沿应用的完整谱系。建议按顺序学习：先建立 RAG 的理论与原则，再拆解模块化架构的各个组件，进而理解智能体驱动的检索系统与知识图谱增强的 RAG，最后落到领域专属的高级应用。

- **高级 RAG 应用：领域专属实现** — `04_advanced_applications.md`
