# 多智能体系统（Multi-Agent Systems）

本模块从离散消息传递走向连续的场涌现，系统讲解多个智能体如何通信、编排、协调，以及群体层面如何涌现出个体不具备的行为。建议按顺序学习：先建立通信协议的基础，再理解编排机制与协调策略，最后观察涌现行为如何从交互中自组织产生。
