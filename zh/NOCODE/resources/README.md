# 资源（Resources）

本目录用于收纳无代码路线的延伸资源。上游仓库此目录暂无正文，中文镜像保留位置，供后续补充论文、文章、工具与社区链接——凡是能帮助读者继续深入上下文工程的材料，都可以归到这里。

**本目录应包含什么**

- **论文与综述** — 上下文工程、认知工具、语义场等方向的原始文献。
- **工具与产品** — 支持长上下文、检索增强、协议壳实践的现成工具。
- **社区与讨论** — 值得长期跟踪的论坛、仓库与通讯。
- **本仓库内的延伸阅读** — 指向 `40_reference/`（参考手册）、`00_COURSE/`（课程）与 `cognitive-tools/`（认知架构）的入口。

**阅读建议**

本目录是「走出去」的入口，不必通读。建议按当前问题挑一类资源深挖，并记录下自己的疑问——这些疑问往往就是下一轮学习的起点。术语沿用全书：context=上下文、retrieval=检索、cognitive tool=认知工具。
