# 心智模型（Mental Models）

本目录用五个比喻把抽象的上下文工程讲成可以「看见」的东西——不需要写一行代码，也能理解上下文如何生长、消耗、流动、相互影响与转化。每个模型都从日常经验出发，再把同一套结构映射回提示词、词元与上下文场的运作。

**章节导览**

- **花园模型（Garden Model）** — `01_garden_model.md`：上下文是种出来的，不是堆出来的；修剪、间苗与轮作对应删减、精简与更换。
- **预算模型（Budget Model）** — `02_budget_model.md`：上下文窗口是一份有限预算，每一次取舍都是支出决策。
- **河流模型（River Model）** — `03_river_model.md`：信息像水流，关注流速、淤积与改道。
- **生物心理社会模型（Biopsychosocial Model）** — `04_biopsychosocial_model.md`：从生物、心理、社会三层理解系统行为。
- **炼金术模型（Alchemy Model）** — `05_alchemy_model.md`：把原始材料转化为更高阶的结构与意义。

**阅读建议**

建议按「花园 → 预算 → 河流 → 生物心理社会 → 炼金术」的顺序读：前三个偏静态与流动，后两个偏层次与转化。每个模型都能单独使用，但组合起来才构成完整的心智工具箱。术语沿用全书：context=上下文、token=词元、prompt=提示词、memory=记忆。
