# 进阶整合（Advanced Integration）

本目录用于收纳把前面所有无代码方法整合起来的进阶实践。上游仓库此目录暂无正文，中文镜像保留位置，供后续补充如何把心智模型、实用协议与场技术组合成一套个人的上下文工作流。

**本目录应包含什么**

- **工作流整合** — 把多个协议串成一条完整流水线：感知、组织、执行、校验。
- **跨模块协同** — 心智模型提供直觉，协议提供步骤，场技术提供调节手段，三者如何配合。
- **失败模式** — 整合后常见的过载、漂移、僵化与误用，以及各自的解药。
- **个人化定制** — 如何按自己的领域与习惯裁剪既有方法，而不是照搬。

**阅读建议**

读完 `NOCODE/00_foundations/`、`NOCODE/10_mental_models/`、`NOCODE/20_practical_protocols/` 与 `NOCODE/30_field_techniques/` 之后再看本目录。此时你应当已经有一两个自己常用的协议，本目录帮你把它们连成体系。术语沿用全书：context=上下文、protocol=协议、field=场、orchestration=编排。
