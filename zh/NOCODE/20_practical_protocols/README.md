# 实用协议（Practical Protocols）

本目录收录九类可直接套用的实用协议——从对话、文档、创造、研究、知识、元递归，到可解释性、协作与跨模态。每个协议都是一张「操作清单」：给定输入、遵循步骤、产出可检验的结果，全程无需编程，只需组织语言与上下文。

**章节导览**

- **对话协议** — `01_conversation_protocols.md`：多轮交流中的澄清、追问与收敛。
- **文档协议** — `02_document_protocols.md`：长文档的拆解、摘要与交叉引用。
- **创造协议** — `03_creative_protocols.md`：从发散到收敛的创意流程。
- **研究协议** — `04_research_protocols.md`：问题界定、证据收集与结论验证。
- **知识协议** — `05_knowledge_protocols.md`：知识组织、检索与更新。
- **元递归协议** — `06_meta_recursive_protocols.md`：对流程本身的审视与改进。
- **可解释性协议** — `07_interpretability_protocols.md`：让推理过程可读、可查。
- **协作协议** — `08_collaborative_protocols.md`：人机与多人协作的分工与交接。
- **跨模态协议** — `09_cross_modal_protocols.md`：文本、图像与其他模态之间的信息转换。

**阅读建议**

不必逐篇通读：先按当前任务挑一个协议，照单执行一遍，再回来看它的设计意图。协议的威力不在条文本身，而在于它们可以互相嵌套——对话协议里可以嵌入研究协议，元递归协议可以作用在任何其他协议之上。术语沿用全书：protocol=协议、context=上下文、prompt=提示词。
