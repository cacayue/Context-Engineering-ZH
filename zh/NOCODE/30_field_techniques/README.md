# 场技术（Field Techniques）

本目录用于收纳无需编程即可实践的场技术。上游仓库此目录暂无正文，中文镜像保留位置，供后续补充直接在对话中操作的场级手法：如何「感知」上下文的整体形态，如何用语言调节共振与张力，如何让吸引子自然形成而不靠逐句指令。

**本目录应包含什么**

- **场感知** — 用提问与复述把隐含的上下文结构显式化的手法。
- **共振调节** — 通过措辞、语气与结构重复来强化或削弱某些模式。
- **吸引子引导** — 不指定步骤，而是创造条件让系统自己收敛到目标行为。
- **边界维护** — 在长对话中防止场漂移、主题侵蚀与残差堆积。
- **与课程的关系** — `00_COURSE/08_field_theory_integration/` 给出理论，本目录收纳的是口头可执行的实践版本。

**阅读建议**

先读 `NOCODE/10_mental_models/` 建立直觉，再读本目录的手法。场的技巧大多「不可言传只可体会」，建议边读边在真实对话里试一次，再回来看描述是否对得上。术语沿用全书：field=场、resonance=共振、attractor=吸引子、emergence=涌现。
