# 社区贡献（Contributing）

本目录汇聚上下文工程社区可供参考的贡献材料与协作约定，是从「读懂」走向「参与」的入口。上游仓库此目录暂无正文，中文镜像保留位置，用于收纳后续补充的贡献指南、案例与讨论记录。

**阅读建议**

- 先读仓库根的贡献总则与行为准则，了解提交规范与评审流程。
- 再读本目录补充材料，理解社区在协议壳、模式与评估实践上的既有约定。
- 参与时优先选择有明确验收判据的小改动（术语修正、图注补全、失效链接修复），再逐步承担整篇译文或新协议壳的撰写。

**与其他模块的关系**

本模块与 `70_agents`、`80_field_integration` 同属「空目录写作」一类：上游只留占位，内容由中文镜像依同目录与相邻模块的正文撰写导读。因此这里不追求逐字对应，而是提供可执行的参与路径。
