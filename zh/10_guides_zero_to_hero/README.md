# 上下文工程（Context Engineering）：从零到精通指南


> *「我的语言的界限意味着我的世界的界限。」* —— 路德维希·维特根斯坦
> 
> 上下文工程拓展了这些界限，为人类与 AI 的协作创造了新的可能。


本目录包含注重动手实践的指南，帮助你从上下文工程的基本概念逐步掌握高级技术。每篇指南都建立在前一篇的基础上，构成一条从基础知识到前沿应用的完整学习路径。

##  如何使用这些指南

每篇指南都具备以下特点：
- **自包含** —— 每个文件都可以独立运行
- **循序渐进** —— 概念建立在前面指南的基础上
- **注重实践** —— 每个概念都配有可运行的代码示例
- **可衡量** —— 每项技术都附有用于评估其有效性的指标

##  快速开始

1. **克隆仓库**
   ```
   git clone https://github.com/davidkimai/Context-Engineering.git
   cd Context-Engineering/10_guides_zero_to_hero
   ```

2. **运行第一篇指南**
   ```
   python 01_min_prompt.py
   ```
   
   或者在 Jupyter 笔记本中运行：
   ```
   %run 01_min_prompt.py
   ```

##  学习路径

这些指南按照精心设计的顺序，从基础概念逐步深入高级概念：

###  基础（1-3）
- **[01_min_prompt.py](01_min_prompt.py)**：理解原子提示词的基本原理，并衡量其有效性
- **[02_expand_context.py](02_expand_context.py)**：学习通过示例、角色定义和约束扩展上下文的技术
- **[03_control_loops.py](03_control_loops.py)**：掌握迭代反馈系统和多步骤 LLM 交互

###  高级实现（4-7）
- **[04_rag_recipes.py](04_rag_recipes.py)**：实现检索增强生成（RAG），生成以知识为依据的回答
- **[05_prompt_programs.py](05_prompt_programs.py)**：使用提示词程序创建结构化推理系统
- **[06_schema_design.py](06_schema_design.py)**：设计模式，使上下文保持一致、可验证且可组合
- **[07_recursive_patterns.py](07_recursive_patterns.py)**：探索利用递归模式自我改进的上下文

###  前沿概念（8+）
- **场协议**（指南 8-10）：掌握场论、涌现、残差和吸引子动力学
- **元系统**（指南 11-15）：探索量子语义、自我改进、透明性和跨模态集成

##  涵盖的关键概念

每篇指南都通过实践示例展示上下文工程的关键原则：

| 指南 | 关键概念 | 实际应用 |
|-------|-------------|------------------------|
| 01_min_prompt | 词元（token）预算、原子指令、投资回报率衡量 | 最小可用提示词、效率优化 |
| 02_expand_context | 少样本示例、角色定义、约束 | 模板化上下文、系统化扩展 |
| 03_control_loops | 顺序串联、迭代改进、条件分支 | 多步骤工作流、自我验证 |
| 04_rag_recipes | 检索、片段切分、上下文集成 | 以知识为依据的回答、事实准确性 |
| 05_prompt_programs | 结构化推理、验证协议、组合操作 | 复杂推理、解释系统 |
| 06_schema_design | JSON Schema、验证、结构强制约束 | 一致的输出、结构化数据提取 |
| 07_recursive_patterns | 自我反思、自举、符号残差 | 演化系统、元推理 |

##  每篇指南包含什么

每篇指南都遵循一致的结构：

1. **概念介绍** —— 解释每项技术背后的「为什么」
2. **实现示例** —— 用可运行的代码演示概念
3. **评估方法** —— 如何衡量每种方法的有效性
4. **可视化工具** —— 将过程可视化并理解其运行机制的方法
5. **拓展练习** —— 在所学知识基础上继续深入的建议

##  实验方法

学习上下文工程的最佳方式是动手实验。对于每篇指南：

1. 按照提供的方式**运行示例**
2. **修改参数**，观察它们如何影响结果
3. 使用提供的指标**衡量影响**
4. **组合不同指南中的技术**，创建混合方法
5. **用自己的用例开展实验**，了解这些原则如何应用

##  评估与指标

每项技术都附有用于评估其有效性的指标：

- **词元效率** —— 输出价值与词元成本的对比
- **回答质量** —— 输出与意图的契合程度
- **延迟影响** —— 不同方法的处理时间
- **一致性** —— 多次运行结果的可靠程度
- **涌现特性** —— 会出现哪些意料之外的行为
