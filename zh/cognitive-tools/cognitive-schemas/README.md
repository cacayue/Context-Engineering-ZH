# 认知模式（Cognitive Schemas）

本目录收录认知模式（schema）——把认知工具与架构的操作固化为结构化、可复用的数据定义。模式让智能体、任务、用户、场与领域等概念具备一致的字段与校验规则，是认知架构从设计走向工程落地的关键一环。

**章节导览**

- **智能体模式** — `agentic-schemas.md`：定义智能体的结构与能力字段。
- **领域模式** — `domain-schemas.md`：面向具体领域的模式定义。
- **场模式** — `field-schemas.md`：语义场相关的模式定义。
- **任务模式** — `task-schemas.md`：任务描述与分解的模式定义。
- **统一模式** — `unified-schemas.md`：整合各类模式的统一定义。
- **用户模式** — `user-schemas.md`：用户画像与偏好的模式定义。

**阅读建议**

模式文件多为 JSON/YAML 结构，键名与占位符原样保留，其中自然语言描述按全书术语对照译为中文。建议配合 `cognitive-templates/` 下的模板与 `cognitive-architectures/` 下的架构一起阅读：模式定义「是什么」，模板给出「怎么用」，架构说明「如何组装」。
