# 认知模板（Cognitive Templates）

本目录收录认知模板——可直接套用的提示词骨架，把认知工具的核心操作固化为开箱即用的结构。模板是模式（schema）的可执行形态：模式定义字段，模板把字段组织成引导模型完成特定推理的提示词。

**章节导览**

- **理解模板** — `understanding.md`：引导模型理解问题的模板。
- **推理模板** — `reasoning.md`：引导模型逐步推理的模板。
- **验证模板** — `verification.md`：引导模型自检与验证的模板。
- **组合模板** — `composition.md`：把多个认知工具组合起来的模板。

**阅读建议**

模板中的占位符与代码块结构原样保留，只译块外说明文字。建议按「理解 → 推理 → 验证 → 组合」的顺序阅读，理解认知工具如何串联成完整工作流。
