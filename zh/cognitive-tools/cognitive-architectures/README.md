# 认知架构（Cognitive Architectures）

本目录收录把认知工具组装成可运行智能系统的架构蓝图。如果说原子、分子、细胞、器官是构建模块，那么认知架构就是把这些模块组织成具备推理、记忆、检索与自我改进能力的完整设计。每篇聚焦一类架构视角，从场论基础到可解释性、量子语义，再到研究、教学、求解等专门形态。

**章节导览**

- **场架构** — `field-architecture.md`：以连续语义场为基础的架构。
- **可解释性架构** — `interpretability-architecture.md`：让系统推理过程透明可查的架构。
- **量子架构** — `quantum-architecture.md`：借量子语义框架组织认知操作。
- **重构记忆架构** — `reconstruction-memory-architecture.md`：以重构方式实现记忆的架构。
- **研究架构** — `research-architecture.md`：面向研究任务的架构。
- **求解器架构** — `solver-architecture.md`：面向问题求解的架构。
- **导师架构** — `tutor-architecture.md`：面向教学辅导的架构。
- **统一架构** — `unified_architecture.md`：整合各类视角的统一设计。

**阅读建议**

建议先读场架构与统一架构建立整体图景，再按兴趣深入专门形态。文中带语言标记的代码块（yaml/python）保留语法结构、块内自然语言说明按全书术语对照译为中文；无标记的说明块与 ASCII 图原样保留。
