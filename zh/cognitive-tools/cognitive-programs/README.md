# 认知程序（Cognitive Programs）

本目录收录认知程序——把认知工具与模板编排成可复用的操作序列。程序是认知架构可执行的最小单元：它把理解、推理、验证等工具串成有明确输入输出的处理流程，供上层架构调用。

**章节导览**

- **基础程序** — `basic-programs.md`：认知程序的基本形态与调用方式。
- **进阶程序** — `advanced-programs.md`：组合与递归的进阶程序形态。

**阅读建议**

程序示例多为 Python 代码块，代码语法与结构原样保留，块内自然语言注释按全书术语对照译为中文。建议配合 `cognitive-templates/` 与 `cognitive-schemas/` 阅读：模板定义单个操作，程序把它们编排成流程，模式为流程提供数据结构约束。
